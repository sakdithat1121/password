# Cipher Lab — เว็บแอปเข้ารหัสข้อความ

เว็บแอปภาษาไทยที่ทำงานในเบราว์เซอร์ มี 5 วิธีตามไฟล์ตัวอย่าง: Caesar, Vigenère, Autokey, General substitution และ Beaufort

## เปิดใช้งานบน Windows

1. ติดตั้ง Node.js รุ่นที่รองรับ ES modules (Node.js 18 ขึ้นไป)
2. เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน `.\launch.ps1` หรือ `npm start`
3. เปิด `http://127.0.0.1:4173` ในเบราว์เซอร์
4. กด **ติดตั้งแอป** ในหน้าเว็บ หรือใช้เมนูติดตั้งของ Chrome / Edge
5. กด Ctrl+C ในหน้าต่าง PowerShell เพื่อหยุดเว็บเซิร์ฟเวอร์

ไม่มีแพ็กเกจ npm ภายนอกที่ต้องติดตั้ง และไม่มีการส่งข้อความออกจากอุปกรณ์ แอปจะเก็บไฟล์หน้าเว็บไว้ในเครื่องเพื่อเปิดใช้งานออฟไลน์หลังโหลดครั้งแรก

## ชุดทดสอบ

รัน `npm test` เพื่อทดสอบผลลัพธ์ทั้ง 5 วิธีเทียบกับตัวอย่าง Excel รวมถึงการวนตำแหน่งคีย์ การรักษาตัวพิมพ์ เว้นวรรค ตัวเลข และการจัดการคีย์ที่ไม่ถูกต้อง

## ติดตั้งบนโทรศัพท์หรือเผยแพร่ให้ผู้อื่น

อัปโหลดไฟล์ทั้งหมดไปยังเว็บโฮสต์ที่ให้บริการผ่าน HTTPS แล้วเปิดลิงก์ในเบราว์เซอร์:

- Android: เปิดด้วย Chrome แล้วเลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
- iPhone / iPad: เปิดด้วย Safari แตะ **แชร์** แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
- คอมพิวเตอร์: เปิดใน Chrome หรือ Edge แล้วเลือกไอคอนติดตั้งในแถบที่อยู่

การติดตั้งและ Service Worker ต้องใช้ `localhost` หรือ HTTPS เบราว์เซอร์บางรุ่นจะแสดงคำสั่งติดตั้งผ่านเมนูแทนปุ่มติดตั้งในหน้าเว็บ

## วิธีเข้ารหัสและค่าเริ่มต้น

| วิธี | ค่าเริ่มต้น | หลักการ |
| --- | --- | --- |
| Caesar | D หรือเลื่อน +3 | เลื่อนตัวอักษรตามจำนวนตำแหน่ง |
| Vigenère | CIPHER | บวกค่าตัวอักษรของคีย์วนซ้ำ |
| Autokey | NIGHT | ใช้คีย์เริ่มต้น แล้วต่อด้วยข้อความต้นฉบับ |
| General substitution | BANGKOK | เติมคีย์เวิร์ดที่ไม่ซ้ำในตาราง แล้วอ่านลงตามคอลัมน์เพื่อสร้างชุดอักษรแทน |
| Beaufort | FINE | ลบค่าข้อความออกจากค่าคีย์ |

การคำนวณใช้ตัวอักษรอังกฤษ A–Z ตามตาราง Excel ช่องว่าง ตัวเลข เครื่องหมาย และตัวอักษรภาษาอื่นคงเดิมและไม่นับเป็นตำแหน่งคีย์ ตารางรายละเอียดดาวน์โหลดเป็น CSV ได้

## โครงสร้างไฟล์

- `index.html`, `styles.css`, `app.js` — หน้าจอและตรรกะการเข้ารหัส
- `manifest.webmanifest`, `sw.js`, `icon.svg` — ติดตั้งเป็น PWA และเปิดออฟไลน์
- `icons/` — ไอคอนสำหรับติดตั้งบนเดสก์ท็อปและโทรศัพท์
- `server.mjs`, `launch.ps1` — เปิดเว็บในเครื่องโดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม
